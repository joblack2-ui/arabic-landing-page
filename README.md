# الأثر - Arabic Landing Page

موقع تطبيق الأثر لحفظ الرسائل والتعليقات باللغة العربية.

## 🌐 الموقع المباشر

الموقع متاح على: [https://joblack2-ui.github.io/arabic-landing-page/](https://joblack2-ui.github.io/arabic-landing-page/)

## 📝 المميزات

- ✅ واجهة عربية كاملة (RTL)
- ✅ حفظ الرسائل محليًا باستخدام localStorage
- ✅ معالجة شاملة للأخطاء
- ✅ تصميم حديث وجميل
- ✅ دعم الهواتف الذكية

## 🚀 الإعدادات

لتفعيل GitHub Pages:

1. اذهب إلى **Settings** في المستودع
2. ثم **Pages**
3. تأكد من تحديد **Branch: main** و **Folder: / (root)**
4. احفظ الإعدادات

سيتم بناء الموقع تلقائيًا خلال دقائق!

## 📂 الملفات

- `index.html` - الملف الرئيسي للتطبيق
- `README.md` - هذا الملف

## 💻 التطوير

يمكنك فتح `index.html` مباشرة في المتصفح أو استخدام خادم محلي:

```bash
# استخدام Python 3
python -m http.server 8000

# أو استخدام Node.js
npx http-server
```

ثم افتح `http://localhost:8000` في متصفحك.
